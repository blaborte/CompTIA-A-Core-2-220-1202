Command-Line Quick Reference

Windows Commands (Command Prompt & PowerShell)

Command Description
tasklistDisplays a list of currently running processes.
taskkillTerminates a running process by name or process ID (PID).
sfcSystem File Checker. Scans and repairs corrupted Windows system files. (e.g., sfc /scannow)
chkdskChecks a disk for file system errors and bad sectors. (e.g., chkdsk /f to fix errors)
gpupdateForces an update of Group Policy settings. (e.g., gpupdate /force)
gpresultDisplays the Resultant Set of Policy (RSoP) for a user and computer.
formatFormats a disk to accept Windows files. **Warning: Erases all data.**
diskpartA command-line disk-partitioning utility.
ipconfigDisplays all current TCP/IP network configuration values.
pingTests network connectivity to another device on the network.
tracertTraces the route that packets take to a network host.
netstatDisplays active network connections and ports.
nslookupQueries the Domain Name System (DNS) to obtain domain name or IP address mapping.
netA versatile command for managing network resources (e.g., net use, net user).
shutdownShuts down, restarts, or logs off a computer. (e.g., shutdown /s /t 0)
dirLists the files and subdirectories in a directory.
cdChanges the current directory.
mdCreates a new directory.
rdRemoves a directory.
delDeletes one or more files.
copyCopies files from one location to another.
xcopyCopies files and directory trees. More advanced than copy.
robocopyRobust File Copy. A powerful tool for copying and synchronizing directories.

Linux & macOS Commands (Bash/Zsh Shell)

Command Description
lsLists directory contents. (e.g., ls -l for detailed view)
pwdPrint Working Directory. Shows the current directory path.
cdChanges the current directory.
grepSearches for a specific pattern of text in files.
psDisplays information about currently running processes.
killTerminates a running process by its process ID (PID).
vi / nanoText editors for the command line.
su / sudoSwitch User or Superuser Do. Used to execute commands with elevated privileges.
chmodChanges the permissions (read, write, execute) of a file or directory.
chownChanges the owner of a file or directory.
ifconfig / ipDisplays or configures network interface parameters. (ip is newer)
pingTests network connectivity to another device.
tracerouteTraces the route that packets take to a network host.
netstatDisplays network connections, routing tables, and interface statistics.
nslookup / digQueries DNS servers for information about hosts. (dig is more advanced)
apt-get / yumPackage managers for Debian/Ubuntu (apt-get) and CentOS/RHEL (yum) based systems.
cpCopies files and directories.
mvMoves or renames files and directories.
rmRemoves (deletes) files and directories.
mkdirCreates a new directory.
ddCopies and converts data. Often used for creating disk images or bootable USB drives.
shutdownShuts down or restarts the system. (e.g., shutdown -h now)
