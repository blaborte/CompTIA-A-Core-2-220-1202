Scenario A: The Disappearing Network Drive 🛡️

A user can no longer access their network drive. They can browse the internet. You suspect a recent Windows update reset the firewall profile.

Question 1: Initial Network Profile Check

You suspect the profile reset from "Private" to **"Public"**. What command utility can you use to quickly view the current network connection profiles?

Hint: You need a command to view connection properties, not IP details. (e.g., Get-NetConnectionProfile or netsh interface...)

Question 2: Identify the Firewall Utility

Result: The profile is **Public**. You need to change it back to **Private**. Which utility is designed for managing Windows Firewall settings?

Hint: This utility manages configuration of network interfaces, protocols, and the firewall. (e.g., netsh)

Question 3: Verify the Fix (Port Connectivity)

Fix: You used the correct utility to switch the profile back to **Private**. **Verification:** How can you verify that the server is now reachable on the **SMB port (445)**?

Hint: You need a tool that can attempt a connection to a specific port. (e.g., telnet or Test-NetConnection)

Scenario A Complete! ✅

Summary of Actions:

  • Check Profile: Used netsh interface to confirm the profile was 'Public'.
  • Fix Profile: Used netsh to change the profile back to 'Private'.
  • Verify Port: Used telnet to test connectivity to the server on the SMB port (445).

Scenario B: Win IP/DNS Failure 🚫

A user reports "no internet." You open a command prompt on their machine.

Question 4: Check IP Address

What is the first command you type to check the user's IP configuration?

Hint: This command displays the basic IP, Subnet, and Gateway configuration. (e.g., ipconfig)

Question 5: Fix APIPA Address

Result: The IP address is 169.254.x.x. This is an APIPA address. What two commands (separated by &&) can you run to force the computer to get a new IP from the DHCP server?

Hint: You need to let go of the current IP address and then ask for a new one. (e.g., ipconfig /...)

Question 6: Fix DNS Issue

Fix: The user now has a valid IP (192.168.1.50). They can ping 8.8.8.8 but cannot browse to google.com. What command will clear the local DNS cache?

Hint: This is a switch for the `ipconfig` command. (e.g., ipconfig /...)

Scenario B Complete! ✅

Summary of Actions:

  • Check IP: Used ipconfig to identify the APIPA address.
  • Fix IP: Used ipconfig /release && ipconfig /renew to get a valid IP.
  • Fix DNS: Used ipconfig /flushdns to resolve the DNS issue.

Scenario C: Win Disk Corruption 💾

A user's Windows PC is extremely slow and applications are crashing. You suspect file system corruption on the C: drive.

Question 7: Check Disk

What command will check the C: drive for file system errors and **fix them**? (This command will require a restart).

Hint: The command is "Check Disk," and you need the switch for "fix." (e.g., chkdsk c: /f or /r)

Question 8: Check System Files

Result: The disk check completes, but core OS functions (like the Start Menu) are still broken. What command will scan and repair protected system files?

Hint: This is the System File Checker. (e.g., sfc /...)

Question 9: Repair Windows Image

Result: SFC fails, stating it "found corrupt files but was unable to fix them." What is the *next* command you should use to repair the underlying Windows Component Store image?

Hint: This utility is used for Deployment Image Servicing and Management. (e.g., dism /online /...)

Scenario C Complete! ✅

Summary of Actions:

  • Check Disk: Used chkdsk /f to fix file system errors.
  • Check System Files: Used sfc /scannow to try and repair OS files.
  • Repair Image: Used dism to repair the component store when SFC failed.

Scenario D: Linux Permissions 🐧

A user on a Linux server cannot execute a script named `deploy.sh`.

Question 10: View Permissions

What command do you use to view the current permissions for `deploy.sh` in long format?

Hint: The list command with the "long" flag. (e.g., ls -l ...)

Question 11: Add Execute Permission

Result: The permissions are -rw-r--r--. What command will **add** the **execute** permission for the **user (owner)**?

Hint: Use the "change mode" command with symbolic notation (u+x) or octal (744). (e.g., chmod ...)

Question 12: Change Ownership

Fix: The user can now run the script. **New Task:** You now need to change the **owner** of the script to `jane` and the **group** to `devs`.

Hint: Use the "change owner" command. (e.g., chown ...)

Scenario D Complete! ✅

Summary of Actions:

  • View Permissions: Used ls -l deploy.sh to see -rw-r--r--.
  • Add Execute: Used chmod u+x deploy.sh (or chmod 744).
  • Change Owner: Used chown jane:devs deploy.sh.
