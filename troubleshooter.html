Scenario A: The Disappearing Network Drive 🛡️

A user can no longer access their network drive. They can browse the internet. You suspect a recent Windows update reset the firewall profile.

You connect to their Windows 10 workstation via a remote command prompt.

Question 1: Initial Network Profile Check

You suspect the profile reset from "Private" to **"Public"**. What command utility can you use to quickly view the current network connection profiles?

Hint: You need a command to view connection properties, not IP details.
  • Possible commands: Get-NetConnectionProfile (PowerShell)
  • Possible commands: netsh interface show interface
  • Possible commands: netsh wlan show profiles
  • Possible commands: netsh show interfaces

Question 2: Identify the Firewall Utility

Result: The network profile is set to **Public**. You need to change it back to **Private**. Which utility is designed for managing Windows Firewall settings, including network profiles?

Hint: This utility manages configuration of network interfaces, protocols, and the firewall.
  • Possible commands: netsh (Network Shell)
  • Possible commands: netsh advfirewall
  • Possible commands: netsh firewall (Older Windows)
  • Possible commands: Set-NetConnectionProfile (PowerShell equivalent)

Question 3: Verify the Fix (Port Connectivity)

Fix: You used the correct utility to switch the profile back to **Private**. **Verification:** How can you verify from the command line that the server is now reachable on the **SMB port (445)**?

What command utility should you use to test connectivity to the target server on a *specific* port (445)?

Hint: You need a tool that can attempt a connection to a port, not just send an ICMP echo request.
  • Possible commands: telnet server_ip 445
  • Possible commands: Test-NetConnection -Port 445 (PowerShell)
  • Possible commands: nc -vz server_ip 445 (Netcat/Linux)
  • Possible commands: tnc -port 445 (PowerShell alias)

Scenario A Complete! ✅

Summary of Actions:

You diagnosed a network drive issue caused by a Windows Firewall profile change. Your steps were:

  • 1. Check Profile: Used netsh interface show interface to confirm the profile was incorrectly set to 'Public'.
  • 2. Fix Profile: Used the netsh utility to change the profile back to 'Private'.
  • 3. Verify Port: Used telnet to test connectivity to the server on the required SMB port (445).

Scenario B: No Internet & APIPA Address 🚫

A user reports they can access internal servers by IP address, but cannot browse the internet or access anything by name. You run ipconfig and see an IP address of **169.254.X.X**.

Question 4: Release the APIPA Address

What command and parameter should you use to force the workstation to DROP its current IP configuration (the 169.254.X.X address)?

Hint: The two-step process to reset DHCP is to 'release' then 'renew'.
  • Possible commands: ipconfig /release (Drops current DHCP lease)
  • Possible commands: ipconfig /all (Used for viewing IP information)
  • Possible commands: netsh interface ip reset (Used for full network stack reset)
  • Possible commands: Disable-NetAdapter (PowerShell method to force disconnect)

Question 5: Request a New Address

Fix Step 1: You successfully dropped the APIPA address. **Fix Step 2:** Now, you must instruct the workstation to request a completely new, valid IP address from the DHCP server.

What command and parameter should you use to force the workstation to REQUEST a new IP configuration?

Hint: This is the second half of the DHCP reset.
  • Possible commands: ipconfig /renew (Requests a new DHCP lease)
  • Possible commands: ipconfig /registerdns (Updates DNS registration)
  • Possible commands: netsh interface ip set address (Manual/Static IP configuration)
  • Possible commands: Restart-NetAdapter (PowerShell method to force restart)

Question 6: Verify External Connectivity

Result: The IP address now shows a valid 192.168.1.X address. **Verification:** The user still reports they cannot open any website. What command should you use to quickly verify both **DNS resolution** and basic **external internet connectivity**?

What command should you run to test connectivity to the DNS name google.com?

Hint: This common command uses ICMP and is the first test for both network path and name resolution.
  • Possible commands: ping google.com (Tests both connectivity and DNS)
  • Possible commands: nslookup google.com (Tests DNS resolution specifically)
  • Possible commands: tracert google.com (Tests the path to the destination)
  • Possible commands: Test-NetConnection google.com (PowerShell test)

Scenario B Complete! ✅

Summary of Actions:

You resolved an APIPA (169.254.x.x) address issue by resetting the DHCP client. Your steps were:

  • 1. Release IP: Used ipconfig /release to drop the invalid address.
  • 2. Renew IP: Used ipconfig /renew to request a new one from the DHCP server.
  • 3. Verify Connectivity: Used ping google.com to test both DNS resolution and internet access.

Scenario C: System Freezing and Disk Errors 💾

A user reports their Windows PC is running slow and frequently freezes. You suspect a logical disk issue (file system errors or corrupt indexing).

Question 7: Initial Read-Only Disk Check

What is the correct Windows command-line utility and parameter to perform a **read-only** scan of the local C: drive to identify file system errors?

Hint: The utility is short for "check disk." By default, running it without the /F parameter performs a read-only check.
  • Possible commands: chkdsk C: (Read-only check)
  • Possible commands: sfc /verifyonly (System file integrity check)
  • Possible commands: PowerShell Repair-Volume -Scan
  • Possible commands: diskpart (Used for volume status and attributes)

Question 8: Schedule the Repair

Result: The read-only scan confirms: "Windows has found problems on this disk that need to be repaired." **Action:** You need to automatically **FIX** the file system errors, which requires scheduling for the next boot.

What parameter should you add to the `chkdsk C:` command to scan for and automatically **FIX** the file system errors?

Hint: The parameter stands for **Fix** errors on the disk.
  • Possible parameters: /f (Fixes file system errors)
  • Possible parameters: /r (Locates bad sectors and recovers readable information)
  • Possible parameters: /x (Forces the volume to dismount first)
  • Possible parameters: /b (Re-evaluates bad clusters on the volume)

Question 9: Verify System Files

Fix: You ran chkdsk C: /f. **Verification:** You still want to check the integrity of the **core Windows operating system files** (DLLs, EXEs) to ensure they weren't corrupted.

What command utility is used to scan and restore corrupted core Windows system files from the system cache?

Hint: The utility is short for **System File Checker** and the common parameter is `/scannow`.
  • Possible commands: sfc /scannow
  • Possible commands: dism /online /cleanup-image /checkhealth
  • Possible commands: dism /online /cleanup-image /restorehealth (A more thorough fix)
  • Possible commands: chkdsk /r (Combines file system fix and sector check)

Scenario C Complete! ✅

Summary of Actions:

You fixed a disk corruption issue by following the correct diagnostic and repair sequence. Your steps were:

  • 1. Read-Only Scan: Used chkdsk C: to safely check the disk for errors without making changes.
  • 2. Schedule Repair: Used chkdsk C: /f to schedule a full file system repair on the next reboot.
  • 3. Verify OS Files: Used sfc /scannow to check for and repair any corrupted core Windows system files.

Scenario D: Linux Permission Denied 🐧

A user on a Linux server uploaded a new Python script. When they try to execute it, they receive a **"Permission denied"** error.

Question 10: Verify Permissions

What command and parameter should you run to verify the current permissions assigned to the file, including the owner, group, and execution status?

Hint: This command lists files, and the parameter stands for 'long format' to show details like permissions.
  • Possible commands: ls -l (Long format)
  • Possible commands: ls -la (Long format including hidden files)
  • Possible commands: stat filename (Shows all file metadata including permissions)
  • Possible commands: getfacl filename (Shows access control lists, if configured)

Question 11: Add Execute Permission

Result: Permissions are -rw-r--r-- (execute 'x' is missing). **Fix:** You need to add the execute permission for the file owner and the group.

What is the command and parameter (using the symbolic method) to grant execute permission to the file owner and the group?

Hint: The utility is short for "change mode." Use the symbolic method ('u', 'g', 'o') and the '+' operator to add the 'x' permission.
  • Possible commands: chmod u+x,g+x filename (Symbolic method)
  • Possible commands: chmod 755 filename (Octal method for rwx r-x r-x)
  • Possible commands: chmod +x filename (Adds execute for all users)
  • Possible commands: chown user:group filename (Changes ownership, not mode)

Question 12: Final Verification (Linux)

Fix: You ran the correct command to add execute permissions.

How can you confirm that the file permissions now include the 'x' flag?

Hint: The verification command is the exact same one you used in Question 10.
  • Possible commands: ls -la (To view long format details)
  • Possible commands: ls -l
  • Possible commands: stat filename
  • Possible commands: ls -F (Shows an asterisk * after executable files)

Scenario D Complete! ✅

Summary of Actions:

You solved a "Permission denied" error on a Linux script. Your steps were:

  • 1. Verify Permissions: Used ls -l to see that the execute ('x') permission was missing.
  • 2. Add Permission: Used chmod u+x,g+x to grant execute rights to the user and group.
  • 3. Confirm Fix: Ran ls -l again to confirm the 'x' permission was now present.
