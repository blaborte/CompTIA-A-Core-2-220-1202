CompTIA A+ Core 2 (220-1202)

Exam Details & Core Objectives for the V15 Update

This document outlines the critical information and domain weights for the current CompTIA A+ Core 2 certification (220-1202) based on the latest exam objectives.

Certification Overview

Exam version:
V15; Core 1 and Core 2 exams must be taken from the same version, no mixing allowed
Exam series code:
220-1202 (Core 2)
Launch date:
March 25, 2025
Number of questions:
Maximum of 90 per exam, including multiple-choice, drag-and-drop, and performance-based questions
Length of test:
90 minutes
Passing score:
700 (on a scale of 900)
Recommended experience:
12 months of hands-on experience in an IT support specialist job role
Languages:
English
Retirement:
Usually three years after launch (estimated 2028)
DoD 8140 approved roles:
Technical support specialist, system administrator, and cyber defense infrastructure support specialist

A+ Core 2 Domain Weights & Detailed Objectives

Domain Jump Links

  • 1.0 Operating Systems (28%)
  • 2.0 Security (28%)
  • 3.0 Software Troubleshooting (23%)
  • 4.0 Operational Procedures (21%)

1.0 Operating Systems 28%

  • **1.1** Compare and contrast **Microsoft Windows** editions and features.
  • **1.2** Use appropriate Microsoft Windows **command line tools** (**CMD, PowerShell, DISM, SFC**).
  • **1.3** Use appropriate Microsoft Windows **desktop administrative tools** (**Control Panel, Settings, Device Manager, MMC**).
  • **1.4** Summarize the functions and basic configuration of **macOS** and **Linux** operating systems.
  • **1.5** Given a scenario, set up and configure Windows client **network settings** (**IP, DNS, Gateway, VPN, Proxy**).
  • **1.6** Given a scenario, install, uninstall, and configure operating systems (including boot methods and **UEFI/BIOS**).

2.0 Security 28%

  • **2.1** Summarize the importance of **physical security** measures.
  • **2.2** Explain how to secure the **SOHO wireless network** (including protocols like **WPA3**).
  • **2.3** Compare and contrast common **security threats** (**Malware, Social Engineering, Ransomware, Phishing**).
  • **2.4** Implement basic **security features and policies** (**Firewalls, Antivirus/Antimalware, User Account Control**).
  • **2.5** Given a scenario, follow the proper procedure for **malware removal** and securing the system.
  • **2.6** Summarize **privacy** and **security best practices** (including data destruction).

3.0 Software Troubleshooting 23%

  • **3.1** Given a scenario, troubleshoot Microsoft Windows **operating system problems** (**Boot issues, Application errors, System crashes**).
  • **3.2** Given a scenario, troubleshoot **mobile OS** and **application issues** (**Connectivity, Synchronization, Performance**).
  • **3.3** Given a scenario, troubleshoot **application security issues** (e.g., unauthorized access, application whitelisting).
  • **3.4** Explain and apply **cloud computing** and **virtualization** best practices and basic concepts (e.g., **IaaS, SaaS, Hypervisors**).

4.0 Operational Procedures 21%

  • **4.1** Compare and contrast best practices for **documentation** and **change management**.
  • **4.2** Explain basic principles of **disaster prevention** and **recovery** (e.g., redundant systems, **UPS**).
  • **4.3** Explain best practices for **data backups** and **retention** (e.g., **full, incremental, differential**).
  • **4.4** Given a scenario, use appropriate **communication techniques** and **professionalism** (e.g., etiquette, tone).
  • **4.5** Summarize various **licenses, policies, and regulations** (e.g., **EULA, GDPR, DRP**).

Key Skills Developed

  • **Master core OS functions** on Windows, macOS, and Linux using both GUI and command-line tools.
  • **Secure endpoints** by implementing physical security, encryption, and strong network protocols (**WPA3**).
  • **Troubleshoot and remediate** common OS, application, and mobile device issues, including the **malware removal process**.
  • Apply virtualization concepts and understand **cloud models** like IaaS and SaaS.
  • Maintain **professionalism** and adhere to operational procedures like **change management** and **data retention** policies.
