Key Terms Glossary

ABCDEFGHIJKLMNOPQRSTUVWXYZ

A

Access Control List (ACL)

A list of permissions attached to an object, specifying which users or system processes are granted access to objects, as well as what operations are allowed.

Active Directory

A directory service by Microsoft for Windows domain networks, used for managing permissions and access to network resources.

Administrative Shares

Hidden network shares created by Windows, accessible only to administrators, for managing systems remotely (e.g., C$, ADMIN$).

AES (Advanced Encryption Standard)

A symmetric encryption algorithm used worldwide to secure data. It is the standard for Wi-Fi (WPA2) and other secure communications.

Antivirus

Software designed to detect, prevent, and remove malicious software, such as viruses, worms, and Trojans.

Authentication

The process of verifying the identity of a user or process.

B

Backup

A copy of computer data taken and stored elsewhere so that it may be used to restore the original after a data loss event.

Biometrics

Authentication techniques that rely on measurable physical characteristics that can be automatically checked (e.g., fingerprint, facial recognition).

BitLocker

A full-disk encryption feature included with Microsoft Windows to protect data by encrypting entire volumes.

Botnet

A network of private computers infected with malicious software and controlled as a group without the owners' knowledge, e.g., to send spam.

BYOD (Bring Your Own Device)

A policy that allows employees to bring their own personal devices to work and use them to access company information and applications.

C

Chain of Custody

A documented trail showing the seizure, custody, control, transfer, and disposition of physical or electronic evidence.

Change Management

A systematic approach to dealing with the transition or transformation of an organization's goals, processes, or technologies.

Clean Install

An installation of an operating system on a computer in which the hard disk is formatted and completely erased.

Cloud Computing

The delivery of computing services—including servers, storage, databases, networking, software, and analytics—over the Internet ("the cloud").

CMD (Command Prompt)

The command-line interpreter for the Windows operating system.

Control Panel

A component of Microsoft Windows that provides the ability to view and change system settings.

Cookie

A small piece of data stored on the user's computer by the web browser while browsing a website, used for tracking and session management.

D

DaaS (Desktop as a Service)

A cloud computing offering in which a third party hosts the back end of a virtual desktop infrastructure (VDI).

DDoS (Distributed Denial of Service)

An attack where multiple compromised systems are used to target a single system, causing a denial of service for users of the targeted system.

Defragmentation

The process of reducing the amount of fragmentation on a storage device by physically organizing the contents of the disk to store the pieces of each file close together and contiguously.

DHCP (Dynamic Host Configuration Protocol)

A network management protocol used to automate the process of configuring devices on IP networks.

Directory Service

A software system that stores, organizes, and provides access to information in a computer network's directory (e.g., Active Directory).

Disk Management

A system utility in Windows for managing hard disks and the volumes or partitions that they contain.

DKIM (DomainKeys Identified Mail)

An email authentication method designed to detect forged sender addresses in emails (email spoofing).

DLP (Data Loss Prevention)

A strategy for making sure that end users do not send sensitive or critical information outside the corporate network.

DMZ (Demilitarized Zone)

A physical or logical subnetwork that contains and exposes an organization's external-facing services to an untrusted network, usually the Internet.

DNS (Domain Name System)

The hierarchical and decentralized naming system used to identify computers, services, and other resources reachable through the Internet.

Domain

A group of computers and devices on a network that are administered as a unit with common rules and procedures.

Driver

A software component that lets the operating system and a device communicate with each other.

E

EFS (Encrypting File System)

A feature of Windows that allows users to encrypt files and folders on an NTFS file system volume to protect them from unauthorized access.

Encryption

The process of converting information or data into a code, especially to prevent unauthorized access.

Event Viewer

A component of Microsoft's Windows NT line of operating systems that lets administrators and users view the event logs on a local or remote machine.

F

FAT32 (File Allocation Table 32)

A disk file system architecture used by Microsoft in its Windows operating systems.

File System

The method and data structure that an operating system uses to keep track of files on a disk or partition.

Firewall

A network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.

Firmware

Permanent software programmed into a read-only memory.

Formatting

The process of preparing a data storage device such as a hard disk drive, solid-state drive, or USB flash drive for initial use.

Full Backup

A backup method that makes a copy of all data to another set of media.

G

GPT (GUID Partition Table)

A standard for the layout of partition tables of a physical computer storage device, using globally unique identifiers (GUIDs).

Group Policy

A feature of Windows that facilitates a wide variety of advanced settings that network administrators can use to control the working environment of users and computers.

Guest Account

A standard user account with limited privileges, intended for temporary use.

H

Hardening

The process of securing a system by reducing its surface of vulnerability.

Help Desk

A resource intended to provide the customer or end user with information and support related to a company's or institution's products and services.

HomeGroup

A feature in Windows that allows computers on the same home network to easily share files and printers.

HTTP/HTTPS

Protocols for communication over a computer network. HTTPS is the secure version, encrypting communications.

I

IaaS (Infrastructure as a Service)

A cloud computing model where a vendor provides users access to computing resources such as servers, storage, and networking.

Image Deployment

The process of creating a master image of an operating system, applications, and settings, and then deploying it to multiple computers.

Incremental Backup

A backup that copies only the data that has changed since the last backup operation of any type.

IP Address

A numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.

K

Kernel

The central component of most computer operating systems; it is a bridge between applications and the actual data processing done at the hardware level.

Keylogger

A type of surveillance technology used to monitor and record each keystroke typed on a specific computer's keyboard.

Knowledge Base

A published collection of documentation that includes answers to frequently asked questions, how-to guides, and troubleshooting instructions.

L

LDAP (Lightweight Directory Access Protocol)

An open, vendor-neutral, industry standard application protocol for accessing and maintaining distributed directory information services over an IP network.

Linux

A family of open-source Unix-like operating systems based on the Linux kernel.

M

MAC Address (Media Access Control)

A unique identifier assigned to a network interface controller (NIC) for use as a network address in communications within a network segment.

Malware

Malicious software designed to disrupt, damage, or gain unauthorized access to a computer system. Examples include viruses, spyware, and ransomware.

Man-in-the-Middle (MITM)

An attack where the attacker secretly relays and possibly alters the communication between two parties who believe they are directly communicating with each other.

MBR (Master Boot Record)

A special type of boot sector at the very beginning of partitioned computer mass storage devices like fixed disks or removable drives.

MDM (Mobile Device Management)

Software that allows IT administrators to control, secure, and enforce policies on smartphones, tablets, and other endpoints.

MFA (Multi-Factor Authentication)

An authentication method that requires the user to provide two or more verification factors to gain access to a resource.

MMC (Microsoft Management Console)

A framework that provides a common user interface for performing system administration tasks.

MSCONFIG

A system utility in Windows used to troubleshoot the startup process.

N

NAT (Network Address Translation)

A method of remapping one IP address space into another by modifying network address information in the IP header of packets while they are in transit across a traffic routing device.

NTFS (New Technology File System)

The primary file system used in Microsoft's Windows NT, 2000, XP, Vista, 7, 8, 10, and 11 operating systems.

O

Operating System (OS)

System software that manages computer hardware, software resources, and provides common services for computer programs.

P

PaaS (Platform as a Service)

A cloud computing model in which a third-party provider delivers hardware and software tools to users over the internet.

Partition

A section of a hard disk drive that is separated from other segments.

Patch Management

The process of distributing and applying updates to software.

Permissions

Controls that a computer administrator uses to grant or deny access to resources on a network or computer.

Phishing

A social engineering attack using fraudulent messages to trick a person into revealing sensitive information.

PING

A command-line utility used to test the reachability of a host on an IP network.

Port Forwarding

An application of NAT that redirects a communication request from one address and port number combination to another while the packets are traversing a network gateway.

PowerShell

A task automation and configuration management framework from Microsoft, consisting of a command-line shell and the associated scripting language.

Proxy Server

A server that acts as an intermediary for requests from clients seeking resources from other servers.

PXE (Preboot Execution Environment)

A method for booting a computer from a network interface, rather than from a local storage device.

Q

QoS (Quality of Service)

The use of mechanisms or technologies that work on a network to control traffic and ensure the performance of critical applications.

R

RADIUS (Remote Authentication Dial-In User Service)

A client/server protocol and software that enables remote access servers to communicate with a central server to authenticate dial-in users and authorize their access to the requested system or service.

RAID (Redundant Array of Independent Disks)

A data storage technology that combines multiple disk drive components into a logical unit for data redundancy or performance improvement.

Ransomware

A type of malicious software designed to block access to a computer system until a sum of money is paid.

Recovery Partition

A partition on a disk that contains a backup of the operating system, which can be used to restore the system to its original state.

Regedit

The Windows Registry Editor, a tool for viewing and modifying the Windows registry.

Remote Assistance

A feature of Windows that allows a user to temporarily view or control a remote Windows computer over a network or the Internet to resolve issues.

Remote Desktop Protocol (RDP)

A proprietary protocol developed by Microsoft, which provides a user with a graphical interface to connect to another computer over a network connection.

Restore Point

A saved "snapshot" of a computer's system files, programs, and registry settings at a specific point in time.

Rootkit

Malicious software designed to enable access to a computer or area of its software that is not otherwise allowed and often masks its existence.

S

SaaS (Software as a Service)

A software licensing and delivery model in which software is licensed on a subscription basis and is centrally hosted.

Safe Mode

A diagnostic mode of a computer operating system that runs with a minimal set of drivers and services.

Script

A list of commands that are executed by a certain program or scripting engine.

Server

A computer program or a device that provides functionality for other programs or devices, called "clients".

Service

A program, routine, or process that performs a specific system function to support other programs, particularly at a low (close to the hardware) level.

SFC (System File Checker)

A utility in Windows that allows users to scan for and restore corruptions in Windows system files.

Shell

A user interface for access to an operating system's services. Can be command-line based or a graphical user interface (GUI).

Shoulder Surfing

The direct observation of a user entering their security credentials.

SLA (Service Level Agreement)

A commitment between a service provider and a client, defining the level of service expected from the provider.

SMTP (Simple Mail Transfer Protocol)

An internet standard for electronic mail (email) transmission.

Social Engineering

The use of deception to manipulate individuals into divulging confidential or personal information that may be used for fraudulent purposes.

SPF (Sender Policy Framework)

An email authentication method designed to detect forging sender addresses during the delivery of the email.

Spyware

Software that aims to gather information about a person or organization without their knowledge.

SSO (Single Sign-On)

An authentication scheme that allows a user to log in with a single ID and password to any of several related, yet independent, software systems.

System Restore

A feature in Microsoft Windows that allows the user to revert their computer's state to that of a previous point in time.

T

Tailgating

A physical security breach in which an unauthorized person follows an authorized individual to enter a restricted area.

Task Manager

A system monitor program used to provide information about the processes and applications running on a computer, as well as the general status of the computer.

TCP/IP (Transmission Control Protocol/Internet Protocol)

The suite of communication protocols used to interconnect network devices on the internet.

TKIP (Temporal Key Integrity Protocol)

An older encryption protocol used in the WPA standard for Wi-Fi networks.

Trojan Horse

Malware disguised as legitimate software that can be used by attackers to gain access to users' systems.

Troubleshooting

A form of problem-solving, often applied to repair failed products or processes on a machine or a system.

U

UAC (User Account Control)

A security feature of Windows which helps prevent unauthorized changes to the operating system.

UPnP (Universal Plug and Play)

A set of networking protocols that permits networked devices to seamlessly discover each other's presence on the network and establish functional network services.

V

Virtual Machine (VM)

An emulation of a computer system. Virtual machines are based on computer architectures and provide functionality of a physical computer.

Virus

A type of computer program that, when executed, replicates itself by modifying other computer programs and inserting its own code.

VPN (Virtual Private Network)

A technology that creates a secure, encrypted connection over a less secure network, such as the internet.

W

WAP (Wireless Access Point)

A networking hardware device that allows other Wi-Fi devices to connect to a wired network.

WEP (Wired Equivalent Privacy)

A deprecated security protocol for Wi-Fi networks, known to be insecure.

Whaling

A specific type of phishing attack that targets high-profile employees, such as the CEO or CFO, in order to steal sensitive information.

Windows Defender

An anti-malware component of Microsoft Windows.

Windows Update

A Microsoft service for the Windows operating systems, which automates downloading and installing Microsoft Windows software updates over the Internet.

Workgroup

A peer-to-peer network where each computer is responsible for its own security, rather than being part of a central domain.

Worm

A standalone malware computer program that replicates itself in order to spread to other computers.

WPA/WPA2 (Wi-Fi Protected Access)

Security protocols and security certification programs developed by the Wi-Fi Alliance to secure wireless computer networks.

Z

Zero-Day Attack

An attack that exploits a previously unknown vulnerability in a computer application or operating system.

Zombie

A computer connected to the Internet that has been compromised by a hacker, computer virus or trojan horse and can be used to perform malicious tasks of one sort or another under remote direction.
