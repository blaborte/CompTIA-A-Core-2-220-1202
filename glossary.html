Key Terms Glossary

ABCDEFGHIJKLMNOPQRSTUVWXYZ

A

Access Control List (ACL)

A list of permissions attached to an object, specifying which users or system processes are granted access to objects, as well as what operations are allowed.

Active Directory

A directory service by Microsoft for Windows domain networks, used for managing permissions and access to network resources.

Administrative Shares

Hidden network shares created by Windows, accessible only to administrators, for managing systems remotely (e.g., C$, ADMIN$).

AES (Advanced Encryption Standard)

A symmetric encryption algorithm used worldwide to secure data. It is the standard for Wi-Fi (WPA2) and other secure communications.

Antivirus

Software designed to detect, prevent, and remove malicious software, such as viruses, worms, and Trojans.

Authentication

The process of verifying the identity of a user or process.

B

Backup

A copy of computer data taken and stored elsewhere so that it may be used to restore the original after a data loss event.

Biometrics

Authentication techniques that rely on measurable physical characteristics that can be automatically checked (e.g., fingerprint, facial recognition).

BitLocker

A full-disk encryption feature included with Microsoft Windows to protect data by encrypting entire volumes.

Botnet

A network of private computers infected with malicious software and controlled as a group without the owners' knowledge, e.g., to send spam.

BYOD (Bring Your Own Device)

A policy that allows employees to bring their own personal devices to work and use them to access company information and applications.

C

Chain of Custody

A documented trail showing the seizure, custody, control, transfer, and disposition of physical or electronic evidence.

Change Management

A systematic approach to dealing with the transition or transformation of an organization's goals, processes, or technologies.

Clean Install

An installation of an operating system on a computer in which the hard disk is formatted and completely erased.

Cloud Computing

The delivery of computing services—including servers, storage, databases, networking, software, and analytics—over the Internet ("the cloud").

CMD (Command Prompt)

The command-line interpreter for the Windows operating system.

Control Panel

A component of Microsoft Windows that provides the ability to view and change system settings.

Cookie

A small piece of data stored on the user's computer by the web browser while browsing a website, used for tracking and session management.

D

DaaS (Desktop as a Service)

A cloud computing offering in which a third party hosts the back end of a virtual desktop infrastructure (VDI).

DDoS (Distributed Denial of Service)

An attack where multiple compromised systems are used to target a single system, causing a denial of service for users of the targeted system.

Defragmentation

The process of reducing the amount of fragmentation on a storage device by physically organizing the contents of the disk to store the pieces of each file close together and contiguously.

DHCP (Dynamic Host Configuration Protocol)

A network management protocol used to automate the process of configuring devices on IP networks.

Directory Service

A software system that stores, organizes, and provides access to information in a computer network's directory (e.g., Active Directory).

Disk Management

A system utility in Windows for managing hard disks and the volumes or partitions that they contain.

DKIM (DomainKeys Identified Mail)

An email authentication method designed to detect forged sender addresses in emails (email spoofing).

DLP (Data Loss Prevention)

A strategy for making sure that end users do not send sensitive or critical information outside the corporate network.

DMZ (Demilitarized Zone)

A physical or logical subnetwork that contains and exposes an organization's external-facing services to an untrusted network, usually the Internet.

DNS (Domain Name System)

The hierarchical and decentralized naming system used to identify computers, services, and other resources reachable through the Internet.

Domain

A group of computers and devices on a network that are administered as a unit with common rules and procedures.

Driver

A software component that lets the operating system and a device communicate with each other.

E

EFS (Encrypting File System)

A feature of Windows that allows users to encrypt files and folders on an NTFS file system volume to protect them from unauthorized access.

Encryption

The process of converting information or data into a code, especially to prevent unauthorized access.

Event Viewer

A component of Microsoft's Windows NT line of operating systems that lets administrators and users view the event logs on a local or remote machine.
